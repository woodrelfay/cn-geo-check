# GEO 自测问题包：星桥家政

- 品牌：星桥家政｜行业：家政服务｜核心产品/服务：日常保洁｜地区：广州｜主要竞品：云洁家政
- 问题总数：12（四组各 3 题）｜测试引擎：豆包、Kimi、DeepSeek、腾讯元宝、通义千问

## 测试铁律（先看完再测）

1. 每个问题开一个新会话提问，避免上下文污染；同一引擎的问题在同一天内测完
2. 问题原文一字不改地粘贴，不追加「请推荐品牌」之类的引导语
3. DeepSeek 必须打开联网搜索；其他引擎如有联网/搜索开关同样打开，并记录开关状态
4. 完整保存答案原文（截图或复制文本），不要只记结论——复盘和申诉都靠原文
5. 记录测试日期和引擎版本/模型名；答案会随模型更新漂移，周与周之间比的是同一套题
6. 品牌词的 B1/B2 若完全查无此品牌，先检查品牌全称写法是否与官网一致，再下结论

## 测试账号规范（登录时代的测法）

1. 五个引擎（豆包/Kimi/DeepSeek/元宝/通义）目前都需要登录后才能对话，没有游客模式——用登录账号人工测试，这是本工具的默认方式，不存在「免登录测法」
2. 每个引擎备一个专用测试账号（小号），不要用日常账号：日常账号聊过品牌相关话题后，平台记忆会「认识你」，后续答案会被你的历史带偏，而且这种漂移很难察觉
3. 能关记忆的先关：豆包、通义等在设置里提供记忆开关，测试前关掉；关不掉的引擎靠「逐题新开会话」兜底
4. 涉及城市的题（长尾词/场景词），测试账号的资料地区和定位与品牌目标市场保持一致，或干脆留空——但每周必须一致，不能这周广州下周北京
5. 每周固定同一个账号、同一套提问顺序、尽量同一时段测：绝对纯净的样本不存在，口径恒定，环比数据才可信
6. 用 API 提问测到的是「API 口径」，与消费者在 App 里看到的答案不是一回事；如使用 API，必须在评分表备注里单独标注，绝不与人工实测数据混算

## 评分维度

- **是否提及**：答案里有没有出现品牌名：出现=1，未出现=0（行业/长尾/场景题的关键指标）
- **提及位置**：品牌在推荐名单中的顺序：1/2/3…，未提及填 0；越靠前权重越高
- **准确性**：1-5 分：5=关键事实全对，3=大方向对但有细节错误，1=张冠李戴或编造
- **情感倾向**：正向 / 中性 / 负向：按答案整体措辞判，不按单句
- **竞品出现**：同一答案里出现了哪些竞品品牌名，原样记录，用于对比份额

综合可见度分（本工具口径，0-100）= 提及率×60 + 首推率×20 + (平均准确性/5)×20。口径固定才可周周对比，分数本身不与任何第三方工具通用。
