# cn-geo-check 中国 AI 引擎 GEO 自测包生成器

> 你的品牌在豆包、Kimi、DeepSeek、元宝、通义的回答里出现吗？一条命令生成整套自测包：12 个标准问题 + 60 行评分表 + 周报模板 + 网站基础检查。**零依赖、纯标准库、不需要任何 API Key。**

英文 GEO 工具已经很成熟，但它们只测 ChatGPT / Perplexity / Gemini。国内用户问的是豆包和 DeepSeek，品牌方真正要盯的是这五个引擎——而测它们目前只能靠人工提问。人工测不难，难的是**每周用同一套题、同一套口径测，数据才能对比**。这个工具解决的就是标准化问题。

## 生成什么

```bash
python -m cn_geo_check --brand 星桥家政 --industry 家政服务 --product 日常保洁 \
    --region 广州 --competitor 云洁家政 --url https://example.com --out ./geo-pack
```

输出文件夹里四个文件：

| 文件 | 内容 |
|---|---|
| `01-测试问题包.md` | 12 个问题（品牌词/行业词/长尾词/场景词四组各 3 题）、每题在测什么、6 条测试铁律、5 个引擎的测试卡 |
| `02-评分表.csv` | 12 题 × 5 引擎 = 60 行，列好评分维度：是否提及、提及位置、准确性（1-5）、情感倾向、竞品出现 |
| `03-周报模板.md` | 周报骨架：核心指标表（提及率/首推率/平均准确性/综合可见度分）、发现、动作，强调只填实测数据 |
| `04-网站基础检查.md` | 给了 `--url` 才生成：robots 是否拦截 AI 爬虫、有没有 llms.txt 和 sitemap、首页有没有 FAQ 结构化数据 |

综合可见度分（本工具固定口径，0-100）= 提及率×60 + 首推率×20 +（平均准确性/5）×20。口径不变，周与周才能比。

## 为什么是 12 题、四组

- **品牌词**测「AI 怎么介绍你」：是什么、口碑、和竞品哪个好
- **行业词**测「用户只问品类时推不推你」：这是 GEO 的主战场
- **长尾词**测「问得细时答得准不准」：价格、服务内容、适合谁
- **场景词**测「用户描述处境求推荐时有没有你」：最接近真实成交的问题

## 快速开始

只需要 Python 3.10+，不用 pip install 任何东西：

```bash
git clone https://github.com/woodrelfay/cn-geo-check.git
cd cn-geo-check
python -m cn_geo_check --brand 你的品牌 --industry 你的行业
```

参数：`--brand`（必填）品牌全称；`--industry`（必填）行业品类；`--product` 核心产品/服务；`--region` 服务地区；`--competitor` 主要竞品；`--url` 官网（联网做基础检查）；`--out` 输出目录。

`example/` 里有一份用虚构品牌「星桥家政」生成的完整样例，可以先看效果。

## 测试方法要点（工具里写全了，这里说三条最容易错的）

1. 每个问题开新会话，问题原文一字不改，不追加引导语
2. DeepSeek 必须开联网搜索再问，不然测的是训练记忆不是可见度
3. 答案原文必须存档，只记结论的复盘都是耍流氓

## 说明

本工具生成的是**人工实测**的标准化弹药，不承诺任何引擎的提及率或排名。网站检查只判断机械可验证项；llms.txt 不是已被证实的排名因素，真正决定 AI 引用你的，是内容里有没有可引用的事实、数据和出处。
